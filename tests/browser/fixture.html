Attention as a garden

A working model for keeping observations and relations close together.

Updated 31 Jul 20266 min read

Attention becomes legible when observations and relations stay close together. A note is not a card in a database; it is a page with a visible history and a set of paths onward.

Observations before categories

Record the thing itself first. Classification can follow after the language has settled. This keeps a knowledge garden open to revision.

Field practice

Keep the source and the interpretation in neighboring paragraphs.

Relations carry context

The margin records direct links, backlinks, embedded sources, and the local outline. It behaves like an editor’s proof rail: quiet until a reader needs context.

From Daily review

Patterns are easier to recognize when each source keeps its own name.

Return paths

Backlinks are not endorsements. They are return paths into the notebook’s evolving argument.
