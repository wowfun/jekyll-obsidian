# One vault, three readings

A blog asks what is new. Documentation asks where the reader is. A digital garden asks what is connected. Those are different reading tasks, even when the source notes are identical.

`jekyll-obsidian` keeps one publication and OFM contract, then gives each task a distinct presenter. URLs stay stable while navigation changes around them.
