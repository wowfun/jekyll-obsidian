# 从笔记到发布

写作时，链接、嵌入、callout 和 properties 仍然属于 Obsidian；构建时，公开边界、URL 与关系索引只计算一次。主题只改变读者如何进入这些内容。

Minimal 把首页、按日期排序的 Blog、Docs 和自定义栏目放在同一站点中；Docs 则按目录与 `nav_order` 组织专注的文档手册。
