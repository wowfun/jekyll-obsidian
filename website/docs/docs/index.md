# Documentation

The handbook follows the same directory tree you see in Obsidian. Start with [[Integration|Host Integration]] when adding `website/` to another repository, or [[Getting Started]] when working with the bundled example locally.

- [[Syntax]] and [[Customization]] cover authoring, themes, navigation, and site configuration.
- [[Comments]] covers GitHub Discussions setup, thread identity, privacy, and troubleshooting.
- [[Localization]] covers locale manifests, translation overlays, fallback pages, and SEO behavior.
- [[Deployment]] covers GitHub Pages and base paths.
- [[docs/development/index|Developer Guide]] covers the contributor toolchain, [[docs/development/architecture|architecture]], and [[docs/development/ofm-conformance|OFM contract]].
- [[中文示例|CJK showcase]] demonstrates mixed-script typography and search.
