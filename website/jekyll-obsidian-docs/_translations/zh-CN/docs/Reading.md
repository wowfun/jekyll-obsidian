# 阅读与导航

本页介绍站点的导航、搜索、图谱与阅读操作。主题和功能开关见 [[Customization|自定义]]；文章筛选、平铺阅读、导出与收藏见 [[Archives|归档与收藏]]。

## 标题栏与页面导航

两个主题的顶栏操作均使用图标，涵盖搜索、语言选择和明暗切换。可访问名称与悬停提示说明各项操作；搜索保留 Ctrl/⌘ K 快捷键。重复的栏目标题和描述自动省略，语言菜单宽度适应选项文字。

桌面标题栏放不下的标签页会进入无障碍 More 菜单。移动端 Browse 面板和 Search 对话框的快速导航会复用同一组有序目标和激活状态。Search 会按配置标签筛选快速链接，同时查询笔记正文。没有 JavaScript 时，标题栏链接仍然可见，并会自然换行。从 Minimal 打开 Docs 时会保留 Minimal 站点外壳，同时加入手册目录、页面大纲及上一篇或下一篇链接。

通过标题栏或移动端 Browse 面板切换标签页时，标题栏保持不变，页面内容、当前标签、页面操作按钮和浏览器历史记录随之更新。有归档页面的 Minimal 站点会在所有页面为阅读和导出按钮预留空间，按钮的显示与隐藏不会推移导航；没有归档页面的站点无需预留。侧栏中的文档链接也会保留文档目录。目标页面的语言、标题栏控件、主题资源或内容安全策略不一致，或加载失败时，会使用完整页面导航。禁用 JavaScript 时，链接仍按浏览器的默认方式跳转。

每个 Docs 页面都由服务器渲染完整文档树；JavaScript 导航只替换页面内容与上下文，保留共享外壳。

## 搜索

Search 在 Web Worker 中构建索引。默认搜索标题、别名、标签和笔记摘要；需要匹配正文时，可在[[Customization#输出数量限制|搜索设置]]中启用全文模式。搜索词最多 256 个字符，输入短暂停顿后才发起查询，同一时间只执行一个 Worker 查询。弹窗最多显示 12 条匹配，同时显示匹配总数和简短文本片段。

搜索弹窗打开后立即聚焦输入框，无需等待 Worker 加载；可用 `Ctrl/⌘ K` 打开搜索。Worker 初始化超过 15 秒即超时，Worker 失败时显示不可用提示。Worker 失败后，可在弹窗内修改搜索词重试，也可关闭后重新打开。文档导航会释放上一页的搜索 Worker，包括尚未完成的初始化。搜索模块下载失败会在下次打开时重试；图谱模块下载失败会在下次文档导航时重试。

## 回到顶部

两个主题的索引、文章、文档、归档和收藏页均提供**回到顶部**箭头。只有向下滚动超过一屏后，按钮才会出现在右下角；回到首屏范围内时隐藏。移动端按钮位于底部工具栏上方，并避让翻译提示。按钮显示时，其键盘导航顺序紧随跳至正文链接。激活按钮会将焦点移至正文并平滑回顶；系统偏好减少动态效果时立即回顶，URL 保持不变。此默认行为无需配置，禁用 JavaScript 和打印时按钮均保持隐藏。可通过语言消息 `back_to_top` 翻译其无障碍名称和悬停提示。

将按钮安排在键盘导航顺序前端，是为了在恢复已滚动页面时快速访问；再按 Tab 时会进入顶栏。强制颜色模式下，按钮及其正文焦点目标均保留可见轮廓。

## 阅读时长

两个主题默认在独立博客文章、文档和普通页面的顶部元信息中显示阅读时长，但仅在估算结果超过 2 分钟时显示。恰好 2 分钟时隐藏，2.1 分钟显示「约 3 分钟阅读」。首页、目录页、系统生成页及文章列表不显示。提示随 HTML 构建生成，禁用 JavaScript 也可显示。

中文及其他 CJK 字符按每分钟 400 字，其余文字按每分钟 200 词估算，两者相加后向上取整。词按连续的 Unicode 字母、数字及其组合标记统计。正文标题、列表、表格、引用、行内代码和普通代码块均计入。展开后的嵌入笔记和导入的 GitHub Markdown 按实际正文统计；frontmatter、生成的操作控件与来源标签不计入。图片、公式、Mermaid 图表、音视频和嵌入附件不增加时间，正文中的图片说明正常计入。带有 `hidden`、`aria-hidden="true"` 或主题 `visually-hidden` 类的隐藏内容不计入。这是基于文字长度的粗略估算，不代表理解内容所需的时间。

译文按实际显示的正文计算，包括缺少翻译时显示的默认语言内容。阅读速度与 2 分钟阈值为固定值，不提供单篇覆盖设置。

提示开关和语言文案见 [[Customization#阅读时长|自定义]]。

## 图谱与 Wiki 链接预览

已发布笔记只有在当前语言分区中与另一篇公开笔记存在链接、嵌入、反向链接或反向嵌入时，才会在右侧上下文栏的大纲与关系上方显示一跳图谱。图谱包含当前笔记和最多 31 个直接邻居，按度数和笔记 ID 确定取舍，最多保留 64 条关系，内嵌数据不超过 64 KiB。邻居数量较多时会显示提示。图谱下方始终保留可展开的关联笔记列表。孤立笔记和仅包含自链的笔记不显示局部图谱。节点面积会随其在完整公开图谱中的度数增加。

图谱左侧按钮打开全局图谱，右侧按钮放大当前笔记的局部图谱。紧凑图谱中，按住 Ctrl 或 ⌘ 并滚动滚轮可以指针为中心缩放，普通滚轮用于滚动页面。图谱对话框中可直接滚动滚轮缩放。使用鼠标时，可拖动空白画布平移，拖动相邻节点改变位置；当前节点固定在视觉中心。触屏上，紧凑图谱允许单指滚动页面；展开后可平移、双指缩放和拖动节点。节点使用原生链接，支持浏览器右键菜单和新标签页。Tab 只进入图谱一次，方向键切换节点，Home 和 End 跳至首尾链接，Enter 打开链接。密集图谱在悬停或聚焦时显示更多标签。紧凑图谱隐藏或移出视口后会暂停模拟。

全局图谱数据只在打开对话框时载入。超过 250 个节点、1,000 条关系或 512 KiB 的图谱会在构建时改为小型数量摘要；浏览器提示使用局部图谱或搜索，无需先下载完整关系数据。站点不会生成 `/graph/` 页面或导航标签，因此已发布笔记可以使用该路由。

鼠标在 Wiki 链接上停留 0.3 秒会打开阅读预览，提前移出指针会取消预览。键盘聚焦立即显示目录元数据，不下载笔记正文；按 Alt+ArrowDown 才展开正文并进入预览。普通 Tab 继续移至页面上的下一个控件。展开后的正文经过清理，可独立滚动，到达边界后恢复页面滚动。点击预览标题可以进入目标笔记，正文中的链接只显示为文本。触屏点击原链接会直接进入笔记。

过时的正文请求会被取消。每页最多缓存 20 篇预览正文，加权容量不超过 2 MiB；单篇下载不超过 1 MiB。导航后释放缓存。正文过大或请求失败时，预览保留目录摘要。设置 `previews: false` 可以关闭预览。
