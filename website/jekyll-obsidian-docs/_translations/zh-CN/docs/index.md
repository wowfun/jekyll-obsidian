# 文档

手册沿用任意 Markdown 编辑器中的目录结构，也可以直接使用 Obsidian。要通过 GitHub Actions 发布且不在本地构建，请先阅读 [[Integration|宿主集成]]；要发布第一篇笔记，请阅读 [[Getting Started|快速开始]]。

- [[Publishing|内容发布]]介绍发布范围、页面组织、笔记属性、来源信息和独立 HTML。
- [[Syntax|语法]]介绍 Markdown、Wiki 链接、嵌入和媒体的写法。
- [[Reading|阅读与导航]]介绍标题栏、搜索、阅读时长、图谱和链接预览。
- [[Customization|自定义]]介绍站点信息、主题、导航、页脚、属性显示与输出限制。
- [[Archives|归档与收藏]]介绍文章筛选、按日分组、平铺阅读、Markdown 导出与本地收藏。
- [[Portfolio|作品集]]介绍自动项目集合和公开的 GitHub Markdown 正文。
- [[Comments|评论]]介绍 GitHub Discussions 配置、讨论串标识、隐私边界与问题排查。
- [[Analytics|流量统计]]介绍可选的 Cloudflare 与 Google 访问统计。
- [[Localization|本地化]]介绍语言清单、译文覆盖层、回退页面与 SEO 行为。
- [[Deployment|部署]]介绍 GitHub Pages、base path、自定义域名、canonical 元数据、站点地图和生产检查。
- [[docs/development/index|开发者指南]]介绍贡献者工具链、架构和 OFM 契约。
