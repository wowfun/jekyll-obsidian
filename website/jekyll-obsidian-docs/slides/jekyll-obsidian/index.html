Jekyll Obsidian
Trust boundary
TRUSTED / SAME-ORIGIN 原样发布，
也原样负责。
01 / EXECUTION

作者脚本会作为同源代码运行。

02 / SCOPE

把整个映射目录当作公开内容审查。

03 / DISCOVERY

Raw 页面不会自动进入导航、Search、Graph、Feed 或 sitemap。

自由来自清晰的授权边界，而不是隐式魔法。
